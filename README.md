# Sunrise show concept

Релизная страница для отеля «Санрайз» в Витязево: гость видит опубликованный формат музыкальных вечеров, выбирает даты проживания и номер с тарифом, после чего получает готовый текст заявки для официального канала отеля.

## Что готово

`Программа → Даты проживания → Гости → Номер → Заявка`

- Музыкальные вечера показаны в опубликованном недельном формате: вторник, суббота и воскресенье; программа проходит 2–3 раза в неделю.
- В карточках номерного фонда показаны опубликованные тарифы на период 01.07–25.08.2026: пять категорий и значения 12 800–20 800 ₽.
- В заявку передаются программа, даты проживания, гости, выбранная категория номера и комментарий.
- Форма не отправляет данные автоматически: она собирает готовый текст, позволяет скопировать его и открыть официальный канал отеля.
- Фотографии загружаются локально из `public/assets/sunrise/`; источники, страницы и дата проверки находятся в [manifest.json](./public/assets/sunrise/manifest.json).
- Сверка фактов и официальных источников описана в [content-sources.md](./content-sources.md).

## Источники и технические решения

Изменяемые данные находятся в [src/data/sunrise.ts](./src/data/sunrise.ts): контакты, официальные ссылки, категории номеров, тарифы, питание, бассейн, пляж и вечерняя программа.

- Тарифы и состав номерного фонда взяты с официальной страницы стоимости 2026 и страницы категорий номеров.
- Форма работает как приватный handoff: персональные данные не уходят на сторонний сервер, а пользователь сам копирует сообщение или открывает официальный сайт/канал отеля.
- Страница является статическим сайтом без серверной части; для связи используются официальные контакты и форма отеля.
- Значение глубины детской зоны бассейна не показывается, потому что в официальных материалах встречаются разные значения.
- Локальные изображения сохранены с указанием исходных страниц и URL в [manifest.json](./public/assets/sunrise/manifest.json).
