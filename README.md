# Sunrise show concept

Конверсионная страница для отеля «Санрайз» в Витязево, которая закрывает разрыв между заявленными музыкальными вечерами и бронированием проживания: гость сначала выбирает программу, затем указывает даты и состав гостей, а в конце отправляет структурированную заявку на проверку.

## Маршрут гостя

`Календарь шоу → выбранная программа → даты проживания → условия → заявка`

- Календарь подготовлен к подключению актуального расписания, но сейчас показывает честное состояние «Ближайшие даты шоу уточняются».
- Выбранное событие сохраняется в контексте заявки до финального шага.
- Даты проверяются на корректность: выезд не может быть раньше или в тот же день, что и заезд.
- Финальная отправка работает в локальном демонстрационном режиме и показывает резюме, не выдавая результат за подтверждённое бронирование.
- События аналитики подготовлены через `window`-событие `sunrise-analytics`: `calendar_view`, `show_selected`, `dates_selected`, `request_started`, `request_submitted`.

## Запуск

```bash
npm ci
npm run dev
```

The app is built with React, TypeScript, Tailwind CSS, and the local Vinext runtime used by Sites.

Production-проверка:

```bash
npm run build
npm run lint
npm run export:static
```

The project is prepared for GitHub Pages as a static demo. The request form is intentionally local until a real endpoint or booking integration is configured.

GitHub Pages is published by [.github/workflows/pages.yml](./.github/workflows/pages.yml). The public demo URL is `https://ya-yura.github.io/sunrise-show-concept-20260813/` after the first workflow run completes.

## Где менять данные

Все изменяемые данные находятся в [src/data/sunrise.ts](./src/data/sunrise.ts):

- `shows` — даты и карточки шоу;
- `offers` — предложения;
- `rooms` — категории размещения и условия;
- `includedItems` — подтверждённые элементы опыта;
- `contacts` — официальные контакты;
- `bookingUrl` — ссылка на реальное бронирование, пока намеренно не подключена;
- `officialLinks` и `gallery` — официальные страницы и фотографии.

Каждая изменяемая сущность содержит `confirmed`. В интерфейс попадают только подтверждённые элементы.

## Что подтвердить перед публикацией

- актуальные даты, названия и время шоу;
- наличие номеров на выбранные даты и текущие цены;
- состав конкретного предложения, включая питание и дополнительные условия;
- реальный endpoint формы или интеграцию с бронированием;
- согласие на обработку персональных данных и юридический текст формы.

До подключения backend заявка остаётся локальной демонстрацией. Контакты и факты в концепции взяты из открытых материалов официального сайта `sunrise-hotel.ru`; перед публичным запуском их нужно перепроверить у команды отеля.
